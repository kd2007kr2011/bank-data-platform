## 3. D14 幂等性测试

**测试目的：**

验证同一业务日期连续执行两次 ETL，不会导致 DWD 数据重复或者金额发生异常变化。

**测试方法：**

1. 构造测试贷款及还款数据。
2. 第一次执行指定日期的贷款快照 ETL。
3. 保存第一次执行的结果。
4. 第二次执行相同 ETL。
5. 对比两次执行的所有业务数据。

**验收标准：**

- 快照记录数一致。
- 贷款未还本金一致。
- 同一业务日期、同一贷款不存在重复记录。

## 4. D14 历史重跑测试

**测试目的：**

验证历史业务数据发生变化后，ETL 可以重新计算指定日期的贷款余额。

**测试方法：**

1. 生成原始历史贷款快照。
2. 在测试环境中补录一笔历史还款。
3. 重新执行相应业务日期的 ETL。
4. 比较重跑前后的贷款余额。

**预期结果：**

- 历史贷款余额正确更新。
- 不产生重复业务记录。
- 重跑日志保存处理日期、原因及汇总变化。

## 5. D14 事务回滚测试

**测试目的：**

确保 ETL 在执行过程中出现异常时，能够恢复到执行前的数据库状态。

**测试方法：**

1. 生成正确的贷款快照。
2. 构造不符合 CHECK 约束的数据。
3. 重新执行 ETL。
4. 检查事务是否回滚。
5. 比较失败前后的快照数据。

**验收标准：**

失败的事务不会破坏原有贷款快照。
